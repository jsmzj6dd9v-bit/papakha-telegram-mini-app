# Papakha Exchange Mini App

Telegram Mini App с предварительными котировками Rapira и пошаговым оформлением черновика обмена.

## Локальный запуск

Из папки проекта запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Подключение к Telegram

1. Опубликуйте содержимое папки на HTTPS-хостинге.
2. В BotFather откройте `/mybots` → бот → `Bot Settings` → `Configure Mini App`.
3. Укажите публичный HTTPS-адрес.

## Что уже работает

- мобильный интерфейс в стиле Papakha;
- навигация между разделами;
- пошаговый опрос при нажатии «Начать обмен»;
- выбор валюты, суммы и способа расчёта по одному вопросу за раз;
- проверка суммы;
- локальный черновик заявки;
- копирование заявки;
- актуальные котировки USDT/RUB, BTC/USDT и ETH/USDT;
- предварительный расчёт направлений между RUB, USDT, BTC и ETH;
- резервная последняя котировка с предупреждением, если Rapira временно недоступна;
- интеграция с темой и виброоткликом Telegram.

## Курсы Rapira

Frontend получает котировки через Cloudflare Worker из папки `worker/`. Worker:

- использует публичный `GET /open/market/rates` Rapira;
- применяет `+3%` к продаже USDT и `−3%` к покупке USDT;
- сохраняет последнюю успешную котировку в Cloudflare KV;
- отдаёт Mini App только пары USDT/RUB, BTC/USDT и ETH/USDT.

После развёртывания Worker его адрес `/rates` указывается в `config.js`. Для KZT, AED и USD автоматический расчёт намеренно не выполняется: итоговый курс подтверждает менеджер.

## Что нужно для запуска заявок

Для реальной отправки понадобится сервер бота: валидация `Telegram.WebApp.initData`, хранение заявки и передача её оператору. Токен бота нельзя добавлять в файлы фронтенда.
