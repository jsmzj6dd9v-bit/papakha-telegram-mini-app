# Papakha Exchange Mini App

Статический прототип Telegram Mini App без вымышленных курсов, цен и контактных данных.

## Локальный запуск

Из папки проекта запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Подключение к Telegram

1. Опубликуйте содержимое папки на HTTPS-хостинге.
2. В BotFather откройте `/mybots` → бот → `Bot Settings` → `Configure Mini App`.
3. Укажите публичный HTTPS-адрес.

## Что уже работает

- мобильный интерфейс в стиле Papakha;
- навигация между разделами;
- выбор направления обмена;
- проверка суммы;
- локальный черновик заявки;
- копирование заявки;
- интеграция с темой и виброоткликом Telegram.

## Что нужно для запуска заявок

Для реальной отправки понадобится сервер бота: валидация `Telegram.WebApp.initData`, хранение заявки и передача её оператору. Токен бота нельзя добавлять в файлы фронтенда.
