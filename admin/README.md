# Закрытая админ-панель Papakha Exchange

Панель использует тот же защищённый API, что и Mini App. Вход возможен только через Telegram Mini App для пользователей, заранее добавленных в таблицу `admins`.

В production админ-панель необходимо публиковать на отдельном разрешённом HTTPS-origin. Прямая публикация файлов сама по себе не открывает доступ: сервер проверяет подпись Telegram, роль, серверную сессию, CSRF-токен и срок действия сессии.

Автоматическое исполнение отключено. Менеджер вручную подтверждает оплату, начинает обмен и завершает сделку. Все изменения сохраняются в неизменяемой истории.
